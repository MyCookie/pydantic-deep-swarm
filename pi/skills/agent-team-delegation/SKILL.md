# Agent Team delegation

Use this skill when a project is substantial enough for the supervised Agent
Team runtime. Prepare a typed brief before delegation:

1. State one concrete objective.
2. Enumerate requirements with stable IDs and required/optional status.
3. Record constraints, permitted actions, prohibited actions, and unresolved ambiguities.
4. Add acceptance criteria with verification methods when verification matters.
5. Specify the desired output and context references.

Send only the typed brief through the explicitly configured delegation tool. Do
not pass raw transcripts, credentials, or the full Pi/Hermes tool surface to
workers. Report only the returned status, concise summary, verified artifacts,
and unresolved items.
